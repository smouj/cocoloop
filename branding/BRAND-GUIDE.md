# CocoLoop — Identidad gráfica oficial

## Nombre

**Marca:** CocoLoop  
**Aplicación:** CL Studio  
**Escritura recomendada:** CocoLoop · CL Studio

## Archivos principales

| Archivo | Uso |
|---|---|
| `cocoloop-logo-color.png` | Emblema oficial a color, fondo transparente, 1254×1254 |
| `cocoloop-logo-white.png` | Variante blanca del mismo emblema, fondo transparente, 1254×1254 |
| `cocoloop-symbol.svg` | Símbolo SVG vectorial **simplificado**, diseñado para tamaños pequeños; no reproduce píxel a píxel los PNG |
| `app/assets/cocoloop.ico` | Icono multirresolución de Windows a partir de la imagen a color |
| `app/assets/cocoloop-color-64.png` | Icono exacto a color usado por la interfaz |
| `app/assets/cocoloop-white-256.png` | Variante monocromática para interfaces oscuras |

## Aplicación

El emblema circular de coco es la identidad principal. En la barra lateral se representa sobre fondo oscuro, sin contenedores cuadrados ni sustituciones del diseño. Es conveniente dejar una zona libre de alrededor del 8% del diámetro del emblema cuando se use sobre fondos complejos. Para tamaños inferiores a 24 px, puede preferirse el SVG simplificado si los detalles del PNG dejan de distinguirse.

**Importante:** las ilustraciones PNG de esta entrega son imágenes rasterizadas, no gráficos vectoriales. El SVG incluido está construido con trazados y degradados editables, pero es una simplificación original del emblema. No incluye ningún recurso de FL Studio.
